# Visor XYZ

Abrir `index.html` en un navegador con WebGL 2. Mallas y recorridos de la biblioteca
se cargan directamente, sin servidor ni OBJ. Profundidad real, caras y cámara
orientable. Ver [procedimiento y límites](../../experiments/012-superficies-xyz/README.md).

Sin `recordings/012-solos.js` sólo está disponible el modo de superficies.
La música se representa como actividad visual de una voz; no produce audio ni
controla osci-render. Los controles de selección son locales al visor.
